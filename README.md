# MERN Stack Developer Portfolio

Modular, production-ready portfolio web application built with React, TypeScript, Tailwind CSS, Express, and MongoDB.

## Project Structure
- `client/`: React + TypeScript frontend built with Vite and Tailwind CSS.
- `server/`: Express + Node.js backend with MongoDB/Mongoose.

## Quick Start

### 1. Backend Setup
```bash
cd server
npm install
cp .env.example .env
npm run dev
```

### 2. Frontend Setup
```bash
cd client
npm install
npm run dev
```

The frontend will run on `http://localhost:5173` and communicate with the backend on `http://localhost:5000`.
